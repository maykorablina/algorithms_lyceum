## Регулярные выражения

**Регулярное выражение** — это шаблон, по которому мы ищем фрагменты текста.

Для работы с регулярками в питоне используется библиотека `re` (о ней чать позже)
Пока поговорим просто про регулярки

### Самые базовые элементы

- `a` — буква `a`
- `.` — любой символ (кроме перевода строки)
- `\d` — цифра (`0–9`)
- `[abc]` — один символ из набора
  - `[a-z]` — любая строчная латинская буква
  - `[0-9]` — любая цифра
  - `[0-9a-zA-Z]]` - любая буква (любой регистр)/цифра 
- `[^abc]` - любой символ, кроме того, что в наборе
  - `[^0-9a-zA-Z]` - не буква и не цифра)

**Примеры:**
`a3c9`

- `a` → `a`
- `.` → `a`, `3`, `c`, `9`
- `\d` → `3`, `9`
- `[abc]` → `a`, `c`
- `[a-z]` → `a`, `c`
- `[^0-9]` → `a`, `c`

### Количества (квантификаторы)

- `*` — 0 или больше раз
- `+` — 1 или больше раз
- `?` — 0 или 1 раз
- `{3}` — ровно 3 раза
- `{2,5}` — от 2 до 5 раз

**Примеры:**
`abbb a ab`

- `ab*` → `a`, `abbb`, `a`, `ab`
- `ab+` → `abbb`, `ab`
- `ab?` → `ab`, `a`, `ab`
- `b{3}` → `bbb`
- `b{1,2}` → `bb`

### Группы

- `( ... )` — группа
- `(?: ... )` — несохраняющая группа

**Примеры:**
`ababab`

- `(ab)+` → `ababab`
- `(?:ab)+` → `ababab`
- `(ab){2}` → `abab`

### «Или»

- `A|B` — либо `A`, либо `B`

**Примеры:**
`cat dog bird`

- `cat|dog` → `cat`, `dog`
- `dog|bird` → `dog`, `bird`

### Ленивость

- `*?`, `+?` — минимальное совпадение
- `*`, `+` — максимальное совпадение

**Примеры:**
`<b>text</b>`

- `<.*>` → `<b>text</b>`
- `<.*?>` → `<b>`
