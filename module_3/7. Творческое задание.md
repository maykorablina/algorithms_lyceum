## Как генерировать данные

Между прочим, очень полезный навые!

### Задание №24
```python
import random

def generate_spqr_string(length=1000, seed=None):
    """
    Генерируем случайную строку длины length,
    состоящую только из букв S, P, Q, R.
    """
    if seed is not None:
        random.seed(seed) # Можно установить сид, чтобы каждый раз строка генерировалась одинаково (как мир в майнкрафте)

    alphabet = "SPQR"
    return "".join(random.choice(alphabet) for _ in range(length))
```
