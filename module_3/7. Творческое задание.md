## Как генерировать данные

Между прочим, очень полезный навык!

**Для генерации файлов можете использовать ИИ, но обязательно укажите это!**

### Задание №24
```python
import random

def generate_spqr_string(length, filename, seed=None):
    """
    Генерируем случайную строку длины length,
    состоящую только из букв S, P, Q, R,
    и записываем её в файл filename.
    """
    if seed is not None:
        random.seed(seed)  # Можно установить сид, чтобы строка каждый раз генерировалась одинаково

    alphabet = "SPQR"
    result = "".join(random.choice(alphabet) for _ in range(length))

    with open(filename, "w", encoding="utf-8") as f:
        f.write(result)

# пример использования:
generate_spqr_string(1000, "24.txt")
```

### Задание 26
```python
import random

def generate_pairs_file(filename, n, min_value, max_value, seed=None):
    """
    Создаёт файл следующего формата:
    n
    a1 b1
    a2 b2
    ...
    an bn

    Где ai и bi — случайные числа из диапазона [min_value, max_value].
    """
    if seed is not None:
        random.seed(seed)

    with open(filename, "w", encoding="utf-8") as f:
        f.write(f"{n}\n")
        for _ in range(n):
            a = random.randint(min_value, max_value)
            b = random.randint(min_value, max_value)
            f.write(f"{a} {b}\n")

# пример использования:
generate_pairs_file("26.txt", 5, 1, 100)
```
