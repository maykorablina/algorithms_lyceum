# Творческое задание 

## 📅 Дедлайн

Работа рассчитана на **2 недели**.  
**Дедлайн — 1 марта, 23:59.**


## Задание

Творческое задание посвящено заданиям **№24 и №26 ЕГЭ**.

Работа выполняется **в паре!!**

Каждый участник должен:

- **придумать одно задание в формате №24**
- **придумать одно задание в формате №26**
- **самостоятельно решить свои задания**
- **передать их напарнику для решения**
- **решить задания напарника**

Таким образом, каждый участник:
- придумывает 2 задания
- решает 2 задания

## ⚠️ Требования к заданиям

1. Формат строго соответствует №24 и №26 ЕГЭ
2. Задания должны быть уникальными — копипастить из интернета нельзя
3. Можно использовать в качестве основы задачи с:
   - Решу ЕГЭ  
   - ФИПИ  
   - КомпЕГЭ  
   - других источников  
   **Но итоговая формулировка должна быть вашей собственной**
4. Уровень сложности — средний (не супер простое задание, но и не очень сложное)


## Оформление работы

Работу можно оформить:

- в Markdown  
- в документе Word  
- в презентации  
- в любом наглядном и аккуратном формате  

Главное — чтобы было понятно!


## Что обязательно должно быть в работе

Для каждого придуманного задания необходимо:

1. **Условие задачи** - формулировка в формате ЕГЭ.

2. **Решение**
   Обязательно привести код программы (если решение программное) или приложить Excel-файл (если решение выполняется в Excel).

4. **Описание хода решения**  
   Необходимо подробно описать:
   
   - каким способом вы решали задачу
   - какие шаги выполняли
   - какие идеи использовали
   - какие формулы, алгоритмы или хаки применяли

**Просто приложить код или файл недостаточно — обязательно текстовое объяснение.**

4. **Ответ**  

## 🔁 Взаимная работа в паре

Каждый участник:

- **решает задания своего напарника**
- **оформляет своё решение**
- **указывает полученный ответ**
- **сравнивает его с авторским**

В работе должно быть указано:

- с кем выполнялась работа
- чьи задания вы решали
- какие ответы получили
