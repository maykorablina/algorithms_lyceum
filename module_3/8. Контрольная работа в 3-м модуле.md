# Контрольная работа

**Дата:** 17 марта  
**Время:** 9.00

## Структура контрольной

На контрольной необходимо решить:

- **3 задания из №24**
- **3 задания из №26**

## Задание №24

В заданиях этого номера могут встретиться:

- задачи, решаемые **методом двух указателей**
- задачи, решаемые **с помощью регулярных выражений**

### Обязательное условие

Минимум **одно задание из №24** должно быть решено **с использованием регулярных выражений**.

## Задание №26

В заданиях этого номера могут встретиться задачи, которые можно решать:
- либо **в Excel**
- - либо **кодом**

### Обязательное условие

Минимум **одно задание из №26** должно быть решено **с использованием кода**.


## Сдача работы

1. **Ответы** отправляются в **контест**.
2. **Решения** необходимо **загрузить в Google-форму** — они будут проверяться отдельно.


## Система оценивания (5-балльная шкала)

Всего необходимо решить **6 заданий**:

- **3 задания из №24**
- **3 задания из №26**

За каждое **полностью правильное задание** начисляется **1.5 балла**.

| Количество решённых задач | Баллы |
|---|---|
| 6 | 9 |
| 5 | 7.5 |
| 4 | 6 |
| 3 | 4.5 |
| 2 | 3 |
| 1 | 1.5 |
| 0 | 0 |

### Перевод баллов в оценку

| Баллы | Оценка |
|---|---|
| 7.5 – 9 | 4 |
| 4.5 – 7 | 3 |
| 3 – 4 | 2 |
| 0 – 2.5 | 1 |

### Условия для оценки **5**

Оценка **5** ставится только при выполнении **обоих требований**:

- хотя бы **одно задание №24 решено регулярными выражениями**
- хотя бы **одно задание №26 решено кодом**

## Что можно взять с собой

Разрешается взять с собой **чит-лист по регулярным выражениям**.

### Важно

- чит-лист можно использовать **только по регулярным выражениям**
- любые другие шпаргалки, конспекты и вспомогательные материалы **не допускаются**
